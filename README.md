# PulsePass

Projeto Integrador de Construção de Software da PUCRS, com foco atual no **Pacote 2 — Arquitetura e Infraestrutura de Desenvolvimento**.

## Escopo atual

A entrega atual é documental e reúne a arquitetura C4, o modelo de dados conceitual, a estrutura de mensageria Kafka, o desenho da pipeline e o processo de Gerenciamento da Configuração de Software. A stack aprovada prevê Python/FastAPI no backend e React/TypeScript no frontend.

A implementação da aplicação e o checkpoint do Pacote 3 ficam para outro momento, mediante nova solicitação. Os serviços, testes e infraestrutura executável descritos na especificação são planejamento para essa etapa futura.
