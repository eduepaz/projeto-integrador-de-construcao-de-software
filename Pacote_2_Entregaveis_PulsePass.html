Arquitetura & Componentes

2. Modelo de Dados Conceitual
Dados & Persistência
 production_artifacts/
Technical_Specification.md
(Seção 3: Modelo de Dados Conceitual e Físico)
Acessar no GitHub → 		Diagrama Entidade-Relacionamento (DER) lógico unificado com assentos numerados e lotes gerais, padrão Database-per-Service no PostgreSQL (sem FKs cross-db), restrições físicas GiST/B-tree para garantia estrita de Zero Overselling e controle de expiração por TTL de 10 min.
3. Estrutura de Mensageria Kafka
Streaming & Eventos
 production_artifacts/
Technical_Specification.md
(Seção 4: Estrutura de mensageria e streaming com Apache Kafka)
Acessar no GitHub → 		Topologia com 6 tópicos de domínio e comandos de saga, ordenação total por chaves determinísticas (reservation_id, order_id), padrão Transactional Outbox para eliminar escrita dupla, consumidores idempotentes com deduplicação e resiliência com DLQ, quarentena e replay.
